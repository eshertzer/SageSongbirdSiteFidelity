**Readme**

This file contains R code to analyse the data and create figures for the manuscript "Cues of habitat change and previous success do not modulate songbird breeding-site fidelity across spatial scales":

1. **RELEASE_Fidelity_figs.Rmd:** Markdown script to create figures for the manuscript. This script uses model outputs from the other three scripts.
2. **RELEASE_Fidelity_landscape.Rmd:** Script to estimate site fidelity at the landscape scale, using a robust design mark-recapture model in JAGS.
3. **RELEASE_Fidelity_nestsite.Rmd:** Script to estimate site fidelity at the nest-site scale, using a GLMM in JAGS.
4. **RELEASE_Fidelity_territory.Rmd:** Script to estimate site fidelity at the territory scale, using a GLMM in JAGS.
